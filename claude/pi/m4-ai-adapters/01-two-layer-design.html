Wire formats vs. vendors

How do you support 35 providers without writing 35 network clients? By noticing that providers vastly outnumber protocols. pi's sharpest structural insight is splitting "who you buy from" apart from "what JSON goes over the wire" — one small directory for each.

Two directories, two questions

The nine wire formats — this union from types.ts is the real map of the LLM industry:

Each name corresponds to one module in src/api/, and every such module exports exactly two functions — stream and streamSimple — satisfying the ProviderStreams interface from Module 3. That uniformity is what lets createProvider treat adapters as interchangeable parts.

Why the split pays

Here's the economics. An adapter is expensive: a thousand-plus lines of request building, SSE parsing, event translation, edge cases (you'll read one next lesson). A provider binding is cheap: ~20 lines of URL, auth, and catalog. So when Groq, Cerebras, Together, DeepSeek, xAI and fifteen others all chose to imitate OpenAI's API — and they did, because compatibility attracts customers — pi gets each of them nearly free. One hard adapter, twenty cheap bindings.

The industry calls these "OpenAI-compatible" APIs, and lesson 4.3 will show how compatible they actually are (spoiler: it's a compatibility matrix, not a yes). But even imperfect compatibility beats twenty bespoke clients.

Engineering · The adapter pattern in the wild

Textbook definition: an adapter converts one interface into another, letting incompatible things collaborate. The textbook stops there; production adds the deeper lesson — where you draw the adapter line determines how much of your code stays clean. pi draws it at the event grammar: adapters absorb 100% of provider weirdness and emit only normalized AssistantMessageEvents. Nothing above the line ever branches on "is this Anthropic?"

The two tells of a well-drawn adapter boundary, both visible here: (1) the interface the adapters implement is small (two functions), and (2) adding a new implementation touches zero existing files except a registry. Compare Python's database API (psycopg2, sqlite3 — one DB-API spec, many drivers): same shape. When you meet a new codebase, finding its adapter seams first tells you where the mess is quarantined.
