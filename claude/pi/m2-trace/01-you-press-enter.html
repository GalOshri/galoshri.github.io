You press Enter

For the next seven lessons we follow one message through the whole machine. You've started pi in some project and typed: "what does package.json do?" — and now you press Enter. This lesson covers the journey's first inch: from keystroke to a call on the agent.

How to read this module

We fly at 500 feet. Every stop on the route gets a sentence of "how" and a pointer to the module that gives it the full treatment. If a detail nags at you — good; a later module almost certainly scratches that itch.

Setting: a terminal in raw mode

A terminal normally handles typing for you: it echoes characters, lets you backspace, and delivers input to the program only when you press Enter (so-called "cooked" mode). A rich interface like pi's can't live with that — it needs every keystroke as it happens, to update the display, offer autocompletions, and react to shortcuts. So on startup pi switches the terminal to raw mode: echo off, buffering off, every key delivered immediately as bytes. From that moment, everything you see on screen — including the characters you "type" — is drawn by pi itself. (Module 9 covers this machinery in loving detail.)

Your keystrokes flow into an Editor component — a from-scratch text editor (2,300 lines! with undo, kill-ring, autocomplete) that pi renders at the bottom of the screen. As far as this module is concerned it's a text box. What matters is what happens when Enter arrives.

Three things worth noticing, because they're patterns you'll see everywhere:

  • The handler is assigned, not inherited. onSubmit is just a property on the editor that holds a function. The editor knows nothing about agents or slash commands; it calls whatever function was plugged in. This is how the layers from lesson 1.4 stay separate in practice — the TUI component stays generic, the app supplies meaning.
  • Slash commands are intercepted before the model ever sees them. /model, /settings and friends are app features, not conversation. Only ordinary text falls through to the bottom. (Module 7 returns to slash commands.)
  • The fall-through is one line. await this.session.prompt(text). All the UI drama above it, and the actual "do AI things" entry point is a single method call.

What is this.session?

It's an AgentSession — the coding agent's central object, which wraps the raw Agent from pi-agent-core and adds everything a product needs: saving the conversation to disk, loading settings, running extensions, tracking cost.
