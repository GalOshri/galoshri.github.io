pi: Anatomy of an AI Coding Agent

pi is a real, production AI coding agent — a terminal program where a language model reads your code, edits files, and runs commands. This course dissects its entire codebase: five packages, from the raw bytes of terminal rendering up to the loop that gives a model agency. Every lesson is self-contained, with real code excerpts and diagrams embedded — no repo-juggling required.

Written for someone with a CS background and basic Python: every TypeScript, Node.js, and LLM concept is introduced right where the code first needs it, in a color-coded concept box, always with a Python comparison.
