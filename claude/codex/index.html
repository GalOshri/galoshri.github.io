Codex: Anatomy of OpenAI's Coding Agent

Codex is OpenAI's coding agent — a terminal program where a language model reads your code, edits files, and runs commands on your machine. This course dissects its entire codebase: roughly a hundred Rust crates, from the syscalls that cage an untrusted shell command up to the loop that gives a model agency.

Written for someone who understands agents but hasn't read a large codebase recently, and whose baseline is basic Python. Codex is written in Rust, so Module 2 teaches exactly as much Rust as the rest of the course needs — and every new construct also gets a concept box where it first appears, always with a Python comparison. Every lesson is self-contained: real excerpts and diagrams are embedded, so there is no repo-juggling.
