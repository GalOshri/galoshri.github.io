Concept boxes (five kinds)

Rust · Result and the ? operator

Every fallible call returns Ok(value) or Err(problem). The ? operator means "unwrap it or return the error to my caller" — Python's try/except, except the compiler forces you to handle it and every failure point is visible.

OS · What "arg0" means

Slot zero of a process's argument list is the name it was invoked as, not the file on disk. Because a hard link gives one file several names, a program can read argv[0] and behave like a different tool entirely.

LLM · Tool calling

Instead of replying with prose, the model can reply with a structured request — "call shell with {"cmd": "cargo test"}" — that your program executes and answers.

Engineering · Append-only logs

Never rewrite history; only add to it. Crash-safe by construction, and the full past stays reconstructable.

SDK · Generated types

The TypeScript SDK's types are generated from the Rust protocol crate, so they cannot drift from the wire format.
